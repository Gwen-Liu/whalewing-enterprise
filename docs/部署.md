# 部署服务端

同一个程序，一个端口（默认 8730），同时提供员工端接口和管理端网页。三种装法挑一种。

## 装法

### npm（推荐不用 Docker 的企业）

要 Node.js 24 或更新：

```bash
npx whalewing-enterprise-server@0.2.1-rc.5.1 --data /srv/whalewing-enterprise/data
```

国内网络从国内镜像下载，`--registry` 要写在包名**前面**（写在后面会被当成服务端的参数，报 `Unknown option '--registry'`）：

```bash
npx --registry https://registry.npmmirror.com whalewing-enterprise-server@0.2.1-rc.5.1 --data /srv/whalewing-enterprise/data
```

也可以全局装：`npm install -g whalewing-enterprise-server@0.2.1-rc.5.1`（国内网络同样加 `--registry https://registry.npmmirror.com`），之后直接运行 `whalewing-enterprise-server`。

| 参数 | 环境变量 | 默认 | 说明 |
| --- | --- | --- | --- |
| `--data` | `WWE_DATA` | 当前目录下的 `data` | 数据目录 |
| `--port` | `WWE_PORT` | `8730` | 端口 |
| `--host` | `WWE_HOST` | `0.0.0.0` | 只给本机反向代理用时写 `127.0.0.1` |
| `--trust-proxy` | `WWE_TRUST_PROXY=true` | 关 | 放在 Nginx、Caddy 后面时打开，才能拿到员工的真实地址和 https |

这些也可以写在数据目录的 `server.json` 里：`{ "port": 8730, "host": "127.0.0.1", "trustProxy": true }`。优先级：命令行 > 环境变量 > `server.json`。

### Docker

用仓库里的 `docker-compose.yml`：

```bash
docker compose up -d
docker compose logs whalewing-enterprise   # 看初始化码
```

镜像是 `ghcr.io/gwen-liu/whalewing-enterprise:<版本>`。拉不下来时，从 GitHub Release 下载镜像文件，`docker load -i whalewing-enterprise-<版本>.tar`。自己构建：`docker build -t whalewing-enterprise .`。

数据在 `./data`，以普通用户（uid 1000）运行。

### 源码

```bash
git clone https://github.com/gwen-liu/whalewing-enterprise.git
cd whalewing-enterprise
npm ci
npm run build
npm start
```

## 第一次打开

1. 启动时日志里有一行“初始化码 xxxx-xxxx”，也写在数据目录的 `setup-code.txt`。
2. 浏览器打开 `http://服务器地址:8730/admin/`，填初始化码、企业名称和第一个管理员（所有者）。没有初始化码不能初始化，防止装好还没初始化时被别人抢先。
3. 在“设置”里填**对外地址**（员工连接用的地址），邀请链接按它生成。
4. 在“成员”里建部门、点“邀请成员”生成邀请链接，发给员工。

## HTTPS

员工从外网连接时必须是 https，员工端不连外网的 http 地址。只在公司内网用（服务器地址是 `10.x`、`172.16`～`172.31`、`192.168` 网段）可以直接 http，员工端会提示“连接没有加密”。员工端不信任企业自己签的证书，外网请用正规机构签发的证书（比如 Let's Encrypt 免费证书）。

### 用 compose 里带的 Caddy（最省事）

把 `docker-compose.yml` 里的 `WWE_DOMAIN` 改成你的域名，域名解析到这台服务器，放开 80 和 443 端口，把 `WWE_TRUST_PROXY` 改成 `"true"`：

```bash
docker compose --profile https up -d
```

Caddy 会自动申请和续期证书。

### 放在已有的 Nginx 后面

服务端用 `--host 127.0.0.1 --trust-proxy` 启动，Nginx 配置示例：

```nginx
server {
  listen 443 ssl http2;
  server_name team.example.com;
  ssl_certificate     /etc/letsencrypt/live/team.example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/team.example.com/privkey.pem;
  client_max_body_size 32m;   # 上传技能压缩包最大 20 MB
  location / {
    proxy_pass http://127.0.0.1:8730;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }
}
```

### 放在已有的 Caddy 后面

```caddy
team.example.com {
  reverse_proxy 127.0.0.1:8730
}
```

## 开机自启

### Linux（systemd）

`/etc/systemd/system/whalewing-enterprise.service`：

```ini
[Unit]
Description=鲸翼企业版服务端
After=network-online.target

[Service]
User=whalewing
ExecStart=/usr/bin/env whalewing-enterprise-server --data /srv/whalewing-enterprise/data --host 127.0.0.1 --trust-proxy
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now whalewing-enterprise
```

### Windows

Node.js 程序本身不是 Windows 服务，推荐用 [NSSM](https://nssm.cc/) 包一层：

```bat
nssm install WhalewingEnterprise "C:\Program Files\nodejs\node.exe" "C:\whalewing\node_modules\whalewing-enterprise-server\bin\whalewing-enterprise-server.js" --data C:\whalewing\data
nssm start WhalewingEnterprise
```

不想装别的软件，也可以用“任务计划程序”设成开机运行。

## 备份

数据都在数据目录：`whalewing-enterprise.db`（账号、部门、权限、记录）、`content/`（团队知识、专家、技能的文件）、`server.json`。

- 运行中备份：`whalewing-enterprise-server backup --data <数据目录> --out <备份目录>`，数据库会拿一份一致的副本。
- 或者停掉服务后复制整个数据目录。

## 升级

换新版本的程序，数据目录不动。启动时如果数据要升级，会先自动备份到 `data/backups/` 再升级。数据被新版本升级过以后，不要再用旧版本程序打开（会拒绝启动）。

服务端和员工端靠**接口版本**配合：接口版本相同时可以不同时升级；对不上时员工端会提示该升级哪一边。

## 让员工一次装好

公司给员工预装时，可以在员工电脑上（DSH 已经打开过一次并完全退出后）运行：

```bat
"%ProgramFiles%\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-whalewing@0.2.1-rc.5.2 dsh-whalewing-enterprise@0.2.1-rc.5.1
```

DSH 安装目录以实际为准。
