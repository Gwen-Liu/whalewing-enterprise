# 功能测试用例

按[设计](../docs/设计.md)和界面约定写的用例，测试代码在 `e2e/specs/`，每条测试上面一行注释写出处。最近一次完整运行（`npm run test:e2e`，2026-11-01）：共 **32** 条，全部通过，用时约 1 分 40 秒。

| 测试文件 | 条数 | 怎么跑 |
| --- | --- | --- |
| `specs/admin.test.mjs` | 18 | 测试里起一个服务端（临时数据目录），无头 Chromium 点管理端网页 |
| `specs/team.test.mjs` | 14 | 起服务端，再起一套临时 DSH，用目录联接装上鲸翼个人版和本仓库的员工端，点鲸翼里的页面 |

同一个文件里的用例按顺序跑、共用一个服务端（和一套 DSH），后面的用例接着用前面建好的数据。每条用例都核对：页面没有报错、没有发往外网的请求。

## 管理端（ADM）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| ADM-01 | 初始化向导 | 两次密码不一致、初始化码不对都在表单里说明原因；填对后进概览，侧栏显示企业名；没填对外地址时概览提醒 |
| ADM-02 | 登录和退出 | 密码错提示“登录名或密码不对”；成员账号登录提示不能进管理端；退出后回到登录页，刷新还是登录页 |
| ADM-03 | 部门 | 新建用右侧抽屉、结果右上角提示；“新建下级部门”默认选好上级；改名或移动时上级部门里没有自己和下级；删除用红色居中确认 |
| ADM-04 | 成员 | 新建账号、调部门、重置密码后旧登录失效；停用（确认框写明个人内容不受影响）后令牌马上失效、显示“已停用”；能重新启用；按名字找；所有者没有“停用账号” |
| ADM-05 | 邀请 | 默认邀请到左边选中的部门；链接只显示一次、能复制；浏览器打开链接看到加入说明；邀请记录显示用量和状态；撤销后链接打开显示用不了 |
| ADM-06 | 团队知识 | 加号卡片新建空间（标识自动去掉大写和符号）；新建、修改笔记；别人先改过时保存被拒，提示里有“读取最新内容”，读回后能改；上传 .md；删除笔记 |
| ADM-07 | 可见范围和维护人 | 选“指定部门和成员”后加部门可见、加成员当维护人，卡片上写“研发中心可见 · 维护人：张三” |
| ADM-08 | 团队专家 | 新建后预览显示名称、“团队”和介绍；表单改介绍、技能、提示词后预览跟着变；模板原文写坏保存被拒 |
| ADM-09 | 团队技能 | 新建自带 SKILL.md 且不能删；上传压缩包（外面多一层目录也认）先确认再整体替换；SKILL.md 的 name 写错被拒 |
| ADM-10 | 删除和放弃修改 | 抽屉有改动时按 Esc、点“取消”都先问“放弃修改”，“继续编辑”改动还在；删除内容项用红色居中确认 |
| ADM-11 | 设置 | 改企业名称后侧栏跟着变；对外地址写错被拒、写对后邀请链接用它；原密码错被拒；改密码成功 |
| ADM-12 | 操作记录 | 有前面做过的管理操作；按“部门”“团队内容文件”筛选；不含密码 |
| ADM-13 | 窗口宽度（375、768、1280、1920 各一条） | 每个页面都没有横向滚动；概览卡片每行 2、3、3、6 张；1920 宽时内容区铺开 |
| ADM-14 | 深色模式 | 背景深、文字浅，卡片比背景亮一点 |
| ADM-15 | 响应头和缓存 | 网页带内容安全策略、不许被嵌入；首页不缓存，带指纹的脚本长期缓存；直接打开子页面能进 |

## 员工端「团队」页签（TEAM）

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| TEAM-01 | 没连接时 | 页头写“没有连接企业”；外网 http 地址提示只能用 https；格式不对的邀请链接说明正确格式 |
| TEAM-02 | 用邀请链接加入 | 先弹“你将加入：××”，写服务器地址、内网未加密、加入的部门和身份、企业看不到个人内容；取消不连；两次密码不一致拦下；确认后提示已加入、页头写企业和部门；令牌只在 DSH 凭据存储里，插件自己的文件里没有 |
| TEAM-03 | 团队页签内容 | 能看的空间、专家、技能都在，标“你可以维护”或“只读”；只给别的部门看的空间不出现 |
| TEAM-04 | 专家团队 | 页头写“2 位来自团队”；只读专家菜单只有“查看专家”“复制为我的专家”；维护人编辑专家（抽屉写明由「团队」提供）保存后写回服务端 |
| TEAM-05 | 个人知识 | 搜得到团队笔记，标“团队”、标题是“空间 / 笔记”；打开写明只读；别的部门的笔记搜不到 |
| TEAM-06 | 技能库 | “扩展”筛选里有“扩展 · 团队”一组，团队技能标只读 |
| TEAM-07 | 维护人新建笔记 | 从空间的“…”新建，写到服务端，个人知识里马上搜得到 |
| TEAM-08 | 提交个人笔记 | 抽屉写明只发这一篇；找到自己的笔记、默认路径是文件名；提交后服务端有，个人笔记一字不改 |
| TEAM-09 | 维护人改技能 | 编辑 SKILL.md 保存后写回服务端 |
| TEAM-10 | 同步 | 管理员新加的空间，点工作台“…”里的“刷新”马上出现，提示“团队内容已是最新” |
| TEAM-11 | 连不上服务端 | 刷新提示“同步没成功”并带“重试”；页头标离线、页签说明连不上；团队笔记照常能搜；服务端恢复后刷新就好 |
| TEAM-12 | 账号被停用 | 刷新后页头写“登录已失效”，说明团队内容已撤掉、个人内容都在；专家团队里团队专家撤掉；启用后地址已填好，用账号密码重新登录 |
| TEAM-13 | 退出团队 | 居中确认写明个人内容不受影响；退出后页头“没有连接企业”；专家、知识、技能里的团队内容都撤掉；凭据存储里的令牌删掉；技能缓存清空；个人笔记还在 |
| TEAM-14 | DSH 日志 | 没有鲸翼企业版启动失败或更新团队专家失败的报错 |

## 写这些测试时发现并修掉的问题

- 管理端编辑抽屉底部的“取消”直接关闭，不问“放弃修改”（Esc、× 会问）。现在“取消”由抽屉组件统一放，走同一条确认。
- 管理端“谁能看”“维护人”外面套的是 `<label>`，点说明文字会把可见范围误切回“全员”。现在用分组容器。
- 员工端登记给鲸翼的技能目录如果写成短文件名（如 `QIANQI~1`）或经过联接，鲸翼和 DSH 报上来的真实路径对不上，团队技能不显示。现在登记前先换成真实路径。

## 还没覆盖的

- DSH 桌面版（Electron）里没跑，这里用的是 DSH 的网页界面。
- 员工端的深色模式、窄窗口和装了皮肤的样子。
- 用团队专家真的开会话、让模型调用团队技能（要真实模型，功能测试不调模型）。
- 离线超过企业规定天数后团队内容收起来（时间在单元测试里用假时钟测了）。
