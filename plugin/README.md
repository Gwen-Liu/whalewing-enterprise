# 鲸翼企业版 · 员工端

`dsh-whalewing-enterprise` 是[鲸翼企业版](https://github.com/gwen-liu/whalewing-enterprise)装在员工电脑上的 DeepSeek Harness（DSH）组合包。它连到企业自己部署的服务端，把团队知识、团队专家、团队技能和团队事项放进鲸翼，企业起了助手名称时把小鲸助手换成这个名字。

## 安装

1. 先装鲸翼个人版：在 DSH「插件 → 添加插件」填 `dsh-whalewing@0.2.1-rc.5.4` 或更新的 rc.5 版本（需要带团队内容和助手名称接口的版本；个人版太旧时员工端会报错说明要先升级）。
2. 再填 `dsh-whalewing-enterprise@0.2.1-rc.5.1`，装好后点“立即启用”。国内网络在添加插件时选“中国大陆镜像源”。
3. 打开鲸翼，进「团队」页签，粘贴管理员发的邀请链接；已经有账号的填服务器地址登录。

只支持 DSH `0.2.1-rc.5`。没装鲸翼个人版时，员工端会等鲸翼装好、开启后再加载。

## 连上后有什么

| 团队内容 | 出现在哪 |
| --- | --- |
| 团队专家 | “专家团队”，卡片标“团队”；维护人可以直接编辑，其他人可以查看或复制为自己的专家 |
| 团队知识 | 知识搜索、小鲸引用、模型用的知识工具都能搜到；阅读时只读 |
| 团队技能 | 技能库的“扩展 · 团队”一组；专家和小鲸都能调用 |
| 助手名称 | 企业在管理端起了名字时，鲸翼里的小鲸助手换成这个名字；编辑小鲸时名字只读。退出团队后恢复“小鲸助手” |

「团队」页签里能看到自己的企业、部门和身份；维护人可以在这里新建、修改团队笔记，或把自己的一篇个人笔记提交到团队（只发这一篇）。

## 安全和隐私

- 连接前先显示“你将加入：××公司”和服务器地址，确认了才登录。企业维护的专家和技能会让模型在你的电脑上读写文件、执行命令，所以要确认连的是自己的企业。
- 外网地址只能用 https，证书不对不提供“忽略继续”；只有公司内网地址可以用 http，会标明“连接没有加密”。
- 登录令牌存在 DSH 的凭据存储里；退出团队时服务端作废令牌、本机删掉令牌和团队内容。
- 企业看不到你的个人知识、个人技能和会话。
- 连不上服务端时，本机缓存的团队内容照常能用；超过企业设置的天数（默认 7 天）还连不上，会先收起来，连上后恢复。
